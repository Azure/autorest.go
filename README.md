# AutoRest Go Generator

The AutoRest code generator for Go has reached end-of-life and is no longer published nor supported.  As part of retirement, this repository has been archived and is no longer maintained.

## TypeSpec Generator Migraion

Microsoft recommends authoring REST API specifications in [TypeSpec](https://azure.github.io/typespec-azure/docs/intro/) and provides an Azure-focused Go code generator for TypeSpec [here](https://github.com/Azure/typespec-azure/tree/main/packages/typespec-go).
